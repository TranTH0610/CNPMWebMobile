# Bản đồ chức năng của dự án

Tài liệu phản ánh source sau khi sắp xếp ngày 06/11/2026. Đây là bản đồ vị trí code, không phải mô tả chức năng mới.

## Cách tìm code

1. Chọn nhóm chức năng bên dưới để biết file.
2. Trong VS Code nhấn Ctrl+P và dán đường dẫn file.
3. Nhấn Ctrl+Shift+O để tìm hàm; hoặc Ctrl+G nhập số dòng được ghi.
4. Đọc chú thích ngay trên hàm/khối. Dòng kết thúc cho biết phạm vi khối code.
5. Số dòng là ảnh chụp tại thời điểm tạo tài liệu; ưu tiên tìm theo tên hàm sau khi sửa code.
